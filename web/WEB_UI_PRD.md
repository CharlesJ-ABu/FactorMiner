# 量化因子挖掘平台 (Factor Mining Platform) UI/UX 设计方案

本 PRD 定义了 FactorMiner 新一代 Web 界面（基于 React/Vite + FastAPI 前后端分离架构）的交互规范与产品设计方案，旨在提供极具专业感、沉浸感与科技感的研究员工作台体验。

---

## 模块一：全局总控台与策略调度 (Command Center & Launchpad)
> 本模块是研究员的日常工作台，摒弃繁杂的 Web 端代码编辑，专注全局指标纵览与计算任务下发。

### 1. 全局指挥中心 (Command Center)
这是系统的主入口 `/`，作为高信息密度的 Dashboard：
- **心跳探测**：无感获取底层 FastAPI 引擎在线状态（`Engine Online`）。
- **挖掘概览看板 (Metrics Overview)**：汇总任务总数、成功率、以及已沉淀无重复因子的总数。
- **活动时间线 (Timeline)**：展示近 5 次的挖掘历史，绿色/红色标识成功失败，并在摘要中直接展示生成的 Factor Hash。
- **快捷动作入口 (Quick Actions)**：带微动效的渐变色大卡片，一键直达核心模块。

### 2. 任务发射台 (The Launchpad)
前端作为轻量级的控制中心，通过配置化的方式缩小搜索空间，一键触发后端 `FactorMinerDirector`。
- **动态 Config 解析**：前端自动请求工作区配置，以下拉框选择 Miner Engine 和 JSON Config。提供 Dashboard 摘要卡片（展现配置中的 Pair, Iterations, Timeframe 等信息）。
- **真异步一键发射 (Launch)**：配置完成后，点击“Start Mining”按钮，前端将参数打包 POST 至后端 `/api/launch`，后端借助 `BackgroundTasks` 分配独立线程，永不阻塞前端主渲染流。

### 3. 实验追踪大厅 (Experiment Tracker)
采用高信息密度的列表设计与**居中模态弹窗 (Modal)**，掌控全局进度。
- **独立任务行**：每一次挖掘任务作为独立数据行展示在宽表中。
- ** WebSocket 微秒级推送**：任务行内的进度条 (Progress) 与状态字通过 `ws://localhost:8000/ws/monitor` 实时刷新。
- **全能监控弹窗 (Omni-Modal)**：点击特定任务行，页面中央弹出宽屏模态弹窗。弹窗内部按垂直维度排布：
  - **基础元数据**：显示 Status、Progress、Config、报错日志或最终生成的顶级 Factor Hash。
  - **实时适应度演化散点图 (Fitness Scatter)**：集成 ECharts，动态打点展示当前任务每一个 Epoch 的因子复杂度和 IC 演化。
  - **执行控制台 (Execution Console)**：专属的暗色背景终端风格日志区，实时滚动当前挖掘任务（LLM、GP、RL 等）的底层运行日志和状态过程。
  （注：通过前端筛选 WebSocket Payload 中的 `task_id`，确保不同任务的监控互不干扰）

## 模块二：挖掘过程的沉浸式监控 (Mining Process Monitoring)
> 解决 `director.run()` 长时间运行时的“黑盒”焦虑，将枯燥的等待转化为极具心理“爽感”的视觉反馈。

### 1. 实时适应度散点图 (Fitness Scatter & 赛马图)
- **图表轴线**：X 轴设定为 Epoch 推进进度，Y 轴设定为核心评价指标（如 IC 或 Sharpe Ratio）。
- **动态渲染**：随着 Epoch 的迭代，前端实时打点。不同颜色代表不同因子的谱系分支。
- **视觉反馈**：研究员可以直观地看着代表因子的点阵不断向右上方（高收益区）演化和聚集，提供强烈的正向心理暗示。

### 2. LLM 专属监控窗 (Reflection Log)
- **滚动日志流**：针对大模型流派，开设专属的侧边栏或底部抽屉组件，实时滚动展示 LLM 的“反思日志”。
- **逻辑自证**：展示系统如何捕获报错、分析原因并自我纠正生成新因子的全过程，以此建立研究员对系统生成逻辑的信任度。

## 模块三：FactorInspector 因子审查台 (The Tearsheet)
> 因子的详情审查页面，拒绝单一的收益曲线，将 `FactorExpression` 的内在灵魂和外在表现具象化。

### 1. 异构流派的“灵魂可视化”
根据因子生成的底层逻辑，提供差异化的白盒可视化审查工具：
- **GP 流派 (遗传规划)**：前端集成 D3.js 或 G6 (或等效的 Graphviz 可视化)，渲染可交互的节点树状图 (AST Tree)。支持鼠标悬停 (Hover) 高亮，并浮窗展示该节点的局部逻辑（如 `ts_mean(close, 10)`）。
- **NN 流派 (神经网络)**：提供高维数据的降维可视化。展示该通道因子（Channel）在隐空间的三维散点图，或利用热力矩阵图呈现特征重要性（Feature Importance）。

界面不得再展示历史名称 `DL`；旧配置由后端映射为 `NN`，旧 `dl_channel` 档案由 API 归一化后展示。

### 2. 量化硬核图表矩阵
引入专业级金融图表库（如 ECharts, TradingView Lightweight Charts 等封装），提供金融终端级别的交互体验：
- **核心图表**：净值曲线（叠加最大回撤阴影区）、多空对冲收益柱状图、IC 衰减热力图。
- **专业交互**：图表必须支持鼠标框选无级放大、十字光标全局悬浮对齐，满足研究员精细化盯盘的习惯。

## 模块四：闭环操作感与工程化体验 (Closed-Loop Engineering)
> 打通从“发现因子”到“实盘交易”的最后一公里，将后端 `FactorCompiler` 的能力前置到界面上。

### 1. 状态流转徽章
- 在因子详情页（Tearsheet）头部区域，展示清晰的生命周期徽章（例如 `[🔍 已审查]`、`[📦 待编译]`、`[🚀 实盘中]`）。

### 2. 一键编译与实盘上架
- **流转操作**：提供醒目的“部署至模拟盘 / 实盘”按钮。
- **进度反馈**：触发操作后，展示沉浸式的编译进度条。
- **成就弹窗**：完成后弹出成功提示（如：“🎉 因子 `alp_llm_001` 已成功编译为 C++ 算子，推送到交易网关”），赋予研究员极强的成就感和业务闭环体验。

## 模块五：数据管理与准备 (Data Downloader)
> 为因子挖掘提供强有力的数据弹药，提供直观的、如同“选股器”一般的多维度条件筛选与批量下载体验。

### 1. 级联动态元数据引擎
- **无感探查**：当用户切换 `Exchange` (如 Binance、OKX) 时，前端主动通过 `/api/exchange_meta` 实时获取该交易所支持的 `Symbols`（代币）、`Timeframes`（周期）与 `Trade Types`（现货/合约）。如果遇到网络封锁，后端探针自动降级到本地白名单，保证前端下拉框永远有数据。
- **动态均分排版**：顶部交互区 (Exchange, Trade Type, Timeframes) 采用极简的、基于内容紧密包裹的 Flex 布局，保证视觉层面的绝对对齐和极度舒适的等距感。

### 2. 批量覆盖透视与并发下载 (Batch Coverage & Download)
- **多选交互**：`Symbols`、`Timeframes` 与 `Trade Types` 全部支持多选 (Multi-Select)。用户可以任意组合。
- **覆盖率透视网络**：一旦点击 "Check Coverage"，后端会自动展开多维参数的笛卡尔积排列组合。前端渲染一张清晰的宽表，逐条展示 `Symbol + Trade Type + Timeframe` 的当前本地数据是否为空、数据段覆盖到哪一年哪一月，红绿相间一目了然。
- **一键并发覆盖**：提供合并、强覆盖等操作选项，任务提交后交由后端 WebSocket 线程池并发处理。
- **Data Downloader 执行控制台 (Execution Console)**：在批量下载过程中，前端下方直接展示类似终端的黑暗风格日志窗口，实时打印后端爬虫（CCXT）拉取每根 K 线的状态、重试、错误及下载完成的信息。提供极具沉浸感的运维级观察体验。
